# CRUD 

## Descripción

Este es un proyecto introductorio que implementa las operaciones básicas CRUD (Crear, Leer, Actualizar, Eliminar) para gestionar datos de forma interactiva. Es una aplicación web ligera y funcional construida con tecnologías frontend fundamentales.


## Estructura del Proyecto

```
CRUD/
├── app.js       
├── index.html   
└── styles.css   
```
## Propósito
Proyecto de aprendizaje para practicar control de versiones con Git/GitHub y aprendizaje de git bash
